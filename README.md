# Tarjetas de presentación

En esta práctica realicé dos tarjetas de presentación utilizando HTML y CSS, siguiendo el diseño que nos dio el profesor.

Utilicé Flexbox para organizar las tarjetas, Font Awesome para los iconos y `clip-path` para crear las figuras. También apliqué media queries para adaptar la página a diferentes pantallas y la metodología BEM para organizar las clases.
